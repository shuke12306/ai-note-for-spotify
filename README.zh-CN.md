# AI Note for Spotify

[English](README.md) · [下载 v1.1.0](https://github.com/shuke12306/ai-note-for-spotify/releases/tag/v1.1.0) · [反馈问题](https://github.com/shuke12306/ai-note-for-spotify/issues)

在 Spotify 播放页直接理解当前作品：翻译长曲名，拆解作品编号、调性和乐章，阅读作品背景、欣赏提示，以及结合当前曲目的演奏者或乐团介绍。使用你自己的 DeepSeek API Key。

**版本 1.1.0 · MIT 许可证。** 插件显示名为 **AI Note**，原名 ClassicalGuide。本版增加独立的简体中文／英文界面切换，电脑检查和 arm64 编译已通过。维护者在 Spotify 9.1.60 环境中的真机反馈与自动化检查分开记录。详见[验证范围](docs/TESTING.md)。

这是通过 TrollFools 注入的独立 iOS 插件，不是 Spotify 官方功能或 Spotify Web API 应用。工程不包含 Spotify 安装包、其他插件或 Premium 功能修改。

## 功能

- 完整播放页中的书本图标与“导赏”入口，适配普通封面和视频／Canvas 布局。
- 中文／目标语言曲名、标题拆解、作品背景、欣赏提示、演奏者／乐团介绍五个 AI 模块，并保留原始曲目信息用于核对。
- 设置内可切换简体中文／英文界面，立即生效、自动保存，重启后保留；初始界面仍为简体中文。
- 十种预设导赏语言和自定义语言，与界面语言独立。切换界面不会重新生成内容或使缓存失效；提示词正文和已有导赏保留原语言。
- 模块排序、开关与独立提示词；单独重新生成，面板内可恢复该模块上一版结果。
- 只生成已开启且没有匹配缓存的模块；修改某个模块的提示词时，其他匹配结果继续复用。
- 持久缓存、离线收藏、内容复制。
- 跟随播放页的背景颜色，可调节文字卡片明暗。

AI 根据曲名、艺术家和专辑信息生成内容，不分析音频，也没有独立资料核验。提示词要求省略缺乏依据的内容，但无法保证输出完全准确。

## 使用

需要手机上的 TrollFools 已能正常配合 Spotify 使用。本工程不提供 Spotify IPA。

1. 完全退出 Spotify，通过 TrollFools 注入一份 AI Note。从 ClassicalGuide 更新时先移除旧的注入项，避免两个名称同时加载。设置、密钥、提示词、缓存和收藏的内部存储标识保持兼容。
2. 播放歌曲，进入完整播放页，点击书本／“导赏”入口。
3. 在设置中输入自己的 DeepSeek Key，选择模型、导赏语言和模块。
4. 配置密钥后，打开或返回导赏页时会自动请求缺少的已开启模块；费用计入你自己的 DeepSeek 账户。
5. 模块右上角的小刷新图标用于单独重新生成；更多菜单中提供收藏、复制等操作。

面板内容绑定打开时的曲目。切歌后重新打开，或主动读取当前曲目；仅播放歌曲不会自动生成导赏。

移除时完全退出 Spotify，再通过 TrollFools 移除本插件。移除 dylib 本身不会自动清除已保存的全部设置、密钥或收藏。

## 隐私与保存

手机通过 HTTPS 直接请求 DeepSeek，发送曲名、艺术家、专辑、语言、模型和提示词。不发送音频、封面、动态视频、Spotify 账号凭据或本地曲目 ID；没有开发者中转服务器或分析 SDK。

API Key 保存在本机 Keychain。普通重启不会清空缓存，但系统可以清理临时缓存；模块缓存上限为 100 组曲目／模型／语言组合、4 MiB。收藏独立存储，上限 200 篇、16 MiB，清缓存不会删除收藏；卸载 Spotify 可能丢失本地内容。

插件与 Spotify、其他注入代码共享进程环境。配置密钥、分享截图或诊断前，可阅读[隐私说明](docs/PRIVACY.md)。
